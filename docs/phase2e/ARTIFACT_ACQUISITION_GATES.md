## Actual execution manifest to create only during authorized E0

Record manifest/schema version, owner authorization and license review references; repository/tag/commit/tree and selected Git blob identities; compressed and decompressed size/SHA-256; per-image original size/hash and curation license/attribution; private quarantine/clean derivative references and scan/decoder versions; artifact rights/retention/revocation state; worker container/wheel/SBOM/dependency hashes; exact preprocessing/dtype/CPU/thread configuration; embedding-space canonical document/digest; resource limits and allowed deployment instance. An independent approver binds an immutable manifest digest to the execution authorization. No self-approved manifest uploaded by a staff browser.

Null hashes in today's proposal remain explicit unknowns; no placeholder can be enabled. Approval binds actual bytes after acquisition, not just filenames. The acquisition approval allows bounded verification, not parsing before gates A3–A5, broad license acceptance, model training or use of unrelated files. Record all rejected attempts without logging media/credentials; preserve original failures privately.

## Revocation and distribution

Maintain separate revocation epochs for image permission, model manifest and deployment. Withdrawing any authority blocks queued and running job publication, new candidate reads and media access; tombstones trigger descriptor/chip/index/result cleanup with audit references. Restore reconciles current revocations before reopening. If a publisher's grant changes at a mutable head, preserve the exact historical evidence and seek review; never silently claim the new terms apply retroactively or that prior permission cannot be challenged.

No weights/images in the public Git repository, package registry or Actions artifacts. Approved actual-byte assets may reside in a private immutable demo artifact store, with per-run short-lived acquisition credentials kept out of fork/untrusted-PR jobs. Tests on a fork cannot silently omit the actual-inference gate and appear successful: run in a controlled reviewed context or remain blocked/pending. Never use `pull_request_target` to execute untrusted changes with asset-store credentials. Runtime remains offline. Any permitted distribution must carry BSL/third-party notices and the applicable CC0/CC-BY-SA attribution/curation terms; application code licensing is not silently changed by an asset import.
