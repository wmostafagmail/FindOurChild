## Exact revised surface

`config/phase2e/source-projection.json` version 2 names 1,141 pinned code/license blobs, 14,274,490 bytes. Both frontal-detector headers, `tools/python/**`, `dlib/python/**`, `dlib/python.h`, root Python packaging scripts, sample photographs/data and unused vendored codecs are excluded. A content sentinel also rejects known embedded pretrained-detector material before writing it into a build projection. This is a bounded source review, not a universal proof about arbitrary future upstream revisions. The original unapproved embedded-header copy remains private, unchanged: 219,037 bytes, SHA-256 `6de4864e431c5696225ae53501b3b9b5223db800c5354b40d48ad1096a76cd52`.

The new `_foc_dlib_native` / `foc-dlib-native==0.1.0` bridge compiles the selected CNN/ResNet/five-point type declarations from the exact dlib baseline and exposes only two bounded RGB-array chip transforms. There is no trained network construction, detector invocation, descriptor generation, model deserialization, image filename/URL loader, HOG detector, pickle callback or operational activation API. Its explicit `model_execution_api_available=false` is a real limitation, not a mocked successful network response. Five-point coordinates in the probe are authored geometry; no aligner weight is used.

The transform fixes RGB uint8, five in-bounds points, 150×150 and padding .25. Native tests compare direct/batch extraction and repeat results; reject wrong dtype, noncontiguous input, four/ten points and out-of-bounds coordinates. Pixel dimensions are bounded at 1600 each. This is generated-array engineering verification; it establishes no photographic quality, facial detection, descriptor accuracy or identity claim.

Build inputs are CPython 3.13.13, pinned Python base-image digests, CMake 3.31.6, NumPy 2.3.3, the pinned core/pybind11 source and project-owned bridge/packager hashes. The wheel is packaged with the Python standard library and carries upstream BSL/BSD notices. The now-unused setuptools/wheel/packaging native-build dependencies were removed; their original advisory findings and patched-profile history remain recorded. Project/application licensing is unchanged. CPU SSE2 is declared; AVX/CUDA/GUI/BLAS/LAPACK and native image-file codecs are disabled. No implicit model/provider/CPU-architecture fallback exists.

The build/runtime remain offline after approved source/dependency acquisition. Nonroot UID 10001, read-only root, no host mounts/capabilities/egress, no-new-privileges and bounded CPU/memory/PID/time/tmp settings are inspected. Actual wheel/image/library/ABI/package/SBOM/notice hashes are exported by the successful source-probe job. The local ARM host is not used as x86_64 compatibility evidence. No source probe can approve itself or complete E0.
