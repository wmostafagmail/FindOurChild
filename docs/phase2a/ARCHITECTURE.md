## Versioned adapters and safety boundary

`services/api/foc_api/research/pipeline.py` defines immutable space provenance and separate `detect`, `align`, `quality`, `embed` stages. The only executable adapter accepts the hashes of 32 locally generated geometric PNG fixtures. It declares a fixture region; it does not detect faces. Alignment is an integer crop of that declared region; quality measures pixel ranges and explicitly reports face quality as unmeasured. Embeddings are normalized 128-component pixel grids, without neural weights or training. Content hash, stage/schema versions, immutable space identity and synthetic warnings accompany outputs. Unknown bytes, missing subject approval, invalid regions, dimensions, nonfinite/nonunit vectors fail closed. There is no URL/path input, remote download, model cache, pickle/torch loading, demographic inference or automatic largest-face selection.

Space identity hashes code revision, weight-artifact identity, detector, alignment, quality, preprocessing, dimension, normalization, metric, data class and schema versions. The synthetic weight digest denotes an explicit no-weights artifact. Version strings are release identities, not claims of a reviewed upstream checkpoint. Every execution additionally binds the complete Git-source fingerprint and dependency locks. Algorithm changes require a new revision/space and migration; equal vector lengths do not establish compatibility. Real backend loading raises an authorization error unconditionally, even with forged configuration/environment flags.

The static authenticated `GET /identity/research-capabilities` reports only fixed disabled capabilities. It uses the accepted real Keycloak/MFA/session/introspection boundary. It exposes no model registry, image, embedding, case, location, corpus or activation command. The fixed BFF route forwards no browser-chosen upstream URL. Official TesterArmy assertions verify anonymous denial, authenticated flags and denial after logout in all 24 configured targets. Public search, automatic confirmation, custody disclosure and activation stay disabled at backend and BFF boundaries.

## Isolated PostgreSQL/pgvector research store

Applied Phase 0–1C migrations remain unchanged. Additive migrations 0022–0024 provide four FORCE-RLS private relations: operator-issued protocol grants, synthetic datasets, per-image metadata and a fixed `vector(128)` space table. `foc_research` is NOLOGIN/nonowner/NOBYPASSRLS and is not granted to API or worker roles. The isolated test operator can assume it to validate its actual privileges. There is no runtime credential or public service for research vector access.

A grant is additional to active organization membership. Purpose, organization, principal, grant expiry/revocation, membership expiry/revocation, disabled principal, suspended organization and dataset expiry/revocation all constrain access. Neither research staff nor application runtime can issue protocol grants. Dataset/generation and per-image composite foreign keys reject tenant mixing and stale writes. The research role cannot update vectors in place, read operational photos/custody, or access reporter metadata. The API cannot become the research role. Transaction context is trusted-server input; these policies do not defeat an administrator or stolen privileged SQL session. Research transactions use READ COMMITTED; authorization is rechecked at each statement, with bounded offline runs. Strong-isolation snapshot semantics are not a revocation guarantee.

The fixed table physically isolates the sole synthetic embedding space; a CHECK binds exact space ID, dimension and unit norm. Further model/weight/preprocessing spaces require distinct physical storage/migrations and full qualification, not an environment toggle. B-tree scope indexing supports exact candidate retrieval. The security-invoker query reads an authorized probe, opposite-registry gallery from the same dataset/partition, at most three content-ordered photos per case, maximum pair cosine per case, and deterministic score/case ordering, with K bounded to 50. It returns case pseudonyms and similarities only to the offline role. Real PG results are compared with independent Python exact retrieval. No cross-organization federation or production ANN/HNSW index is provisioned. ANN Recall@K/filter parity and capacity remain pending measured justification.

Deleting research photographs cascades vector deletion in the same transaction; stale reinsertion fails its FK. Revoked/expired datasets cannot be searched. This is synthetic research cleanup, not operational child erasure, backup tombstone replay or a legal-retention certification. Existing release blockers remain.

## Historical image metadata

Each research photograph independently preserves capture lower/upper bounds, precision, age lower/upper months, age-reference date bounds, content hash, source, partition, registry and synthetic provenance. Missing dates/ages remain NULL; dates are not inferred from report time and ages are not copied from a case profile. Constraints reject inverted/incomplete intervals, while contradictory testimony requires human interpretation. Exact retrieval applies no hard age exclusion. Existing encrypted Phase 1C per-upload capture metadata and originals remain untouched; research tables do not import operational photos or locations.

## Reproducible evaluation

`evaluation.py` validates finite compatible vectors, content hashes, synthetic-only records, identity/family-disjoint development/calibration/test partitions, duplicate captures and consistent case ground truth. Test gallery/probe roles and opposite registries are explicit. Retrieval has stable photo caps, deduplication, tie ordering and case aggregation. `evaluate` reports Recall@1/10/50, query/subject macro recall, explicit mate-present/absent denominators, FPIR, TPIR/FNIR at the frozen synthetic threshold and rank-50 limit, false leads/query and subject-clustered seeded bootstrap intervals. No-mate/no-miss denominators are NULL rather than fabricated zeroes.

Capture-gap strata use all true-gallery capture intervals, including unknown and uncertain-cross-bin rows, so missed retrievals are not omitted from subgroup denominators. Probe capture-age intervals likewise retain unknown/cross-bin cases. No learned age adjustment, hard age filter or probability calibration is introduced. The synthetic smoke harness processes 32 different geometric images and a separate analytic open-set vector, records source/lock/runtime/seed/manifest identity, and repeats metric calculation to check determinism. Timing describes only synthetic Python processing.

Real recognition accuracy, demographic fairness, longitudinal generalization, training overlap, rare-event statistical power, real quality/no-face error rates, neural provider parity and production sizing remain unmeasured. A future lawful dataset requires an independent custodian, subject/family/duplicate review, exact rights and expiry, a frozen calibration/test protocol, confidence/power analysis and owner approvals before loading. Synthetic smoke results cannot establish child recognition performance or an operational threshold.
