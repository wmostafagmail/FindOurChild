# Qualification blockers and approval checklist

All eight real profiles: **blocked**. Preparation review may approve this phase without approving any weight, dataset or model execution. Every item below remains pending for real evaluation; a checked code test is not a substitute for signed external evidence.

- [ ] Owner separately authorizes a specified evaluation-only purpose, dataset and protocol; no operational use.
- [ ] Counsel/DPO verify applicable jurisdictions, lawful originals/biometrics authority, welfare/ethics and guardian/subject safeguards.
- [ ] Exact model, detector, aligner and conversion-chain grants cover this purpose; training-corpus versions/rights/subject authority and overlap reviewed.
- [ ] Immutable artifact references and actual binary hashes verified after lawful acquisition; safe serializer/parser/runtime/provider image and SBOM approved.
- [ ] Independent custodian verifies identities, consent/other authority, provenance, dates/age intervals, withdrawals and capture events.
- [ ] Cohort coverage, independent-subject/family power, rare-event bounds, subgroup limitations and publication policy approved by independent statistician/evaluator.
- [ ] Subject/family/event-disjoint splits, sealed truth/test, calibration-only thresholds, aggregation and full protocol hashes signed before unblinding.
- [ ] Separate real-data infrastructure, credentials/keys, offline workers, grants/egress, audit, revocation/cancellation and incident procedures independently verified.
- [ ] Retention/deletion and backup tombstone replay demonstrated for every real data derivative and restore path.
- [ ] Preprocessing/provider/space parity, FTA/FTE, CPU/GPU capacity and independent real benchmark completed with honest failure counts/uncertainty.
- [ ] Owner reviews evidence and explicitly authorizes the next activity; evaluation approval does not activate operational searching.

Age progression requires its own additional model/data/ethics protocol and approval. No public facial search, automated identity decision or custody disclosure is authorized at any stage of this checklist. No publisher or dataset custodian has been contacted by this work.
