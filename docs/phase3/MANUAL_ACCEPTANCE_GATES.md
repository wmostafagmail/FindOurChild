All sessions use fictional cases and synthetic media, or separately approved demonstration assets only after their acquisition phase is explicitly authorized. A checkbox claiming synthetic input does not authorize arbitrary photographs. No real missing-child record, child release or custody disclosure is a valid test fixture.

Before a session, freeze the reviewed commit, supported device/assistive-technology matrix, fixture manifest and expected outcomes. Use a dedicated demonstration environment with separate credentials. Keep raw recordings, DOM, photographs, tokens and credentials private. Publish only allowlisted, sanitized evidence with task IDs and reviewer sign-off; review captures before publication. A missing session, unavailable tester, skipped essential task or unresolved critical finding remains pending/failed, never passed.

Phase 3 release review must explicitly resolve all three gates. Deferring these sessions from Phase 2D does not waive them. Any new implementation requires its own phase authorization; this document starts no phase and grants no operational or biometric approval.
